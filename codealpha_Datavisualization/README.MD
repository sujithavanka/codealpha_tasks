# Data Visualization - CodeAlpha Internship

## Task Objective
To analyze and visualize the Superstore dataset using Python.

## Dataset
Sample Superstore dataset containing sales, profit, category, and region data.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Steps Performed
- Imported dataset using Pandas
- Cleaned and explored data
- Created visualizations:
  - Sales by Category
  - Sales by Region
  - Sales Distribution

## Visualizations
- Bar chart for category-wise sales
- Region-wise sales analysis
- Distribution plots for sales

## Outcome
Gained insights into sales performance across categories and regions using data visualization.
