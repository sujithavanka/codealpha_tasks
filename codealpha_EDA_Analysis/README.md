CodeAlpha - Exploratory Data Analysis (EDA) Project

Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship. The objective of this project is to perform Exploratory Data Analysis (EDA) on the Sample Superstore dataset and gain meaningful insights through data exploration and visualization.

Dataset

The dataset used in this project is the Sample Superstore dataset, which contains information related to sales, customers, products, categories, regions, and shipping details.

Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Tasks Performed

1. Data Loading and Inspection
2. Data Cleaning
3. Missing Value Analysis
4. Duplicate Record Analysis
5. Statistical Summary of Data
6. Sales Distribution Analysis
7. Region-wise Sales Analysis
8. Category-wise Sales Analysis
9. Segment-wise Sales Analysis
10. Top States and Cities by Sales
11. Product Sub-Category Analysis
12. Data Visualization

Visualizations Created

- Sales Distribution Histogram
- Sales by Region
- Sales by Category
- Sales by Segment
- Top 10 States by Sales
- Top 10 Cities by Sales
- Top 10 Sub-Categories by Sales

Project Outcome

The analysis helped in understanding sales patterns across different regions, categories, customer segments, states, and cities. Various visualizations were used to explore the dataset and identify trends within the business data.
